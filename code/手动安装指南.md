# 数学建模竞赛E题 —— 手动分步安装指南（带国内镜像）

> 本指南适用于 Windows CMD / PowerShell，每一步均可复制粘贴执行。
> 预计总耗时：10~20 分钟（取决于网速）。

---

## 前置检查

打开 CMD 或 PowerShell，依次执行以下命令，确认基础环境：

```cmd
python --version
```
期望输出：`Python 3.13.9`（或 3.9 以上版本）

```cmd
pip --version
```
期望输出：`pip 25.x.x from ...`

如果以上命令报错"不是内部命令"，说明 Python 未加入环境变量，请重新安装 Python 并勾选 **"Add Python to PATH"**。

---

## 第 1 步：升级 pip（基础工具）

```cmd
python -m pip install --upgrade pip
```

**作用**：确保 pip 是最新版，避免旧版安装包时出错。

**验证**：
```cmd
pip --version
```

---

## 第 2 步：永久配置 pip 国内镜像源（清华源）

 pip 默认从国外下载，速度慢且容易超时。配置清华源后永久生效。

### 2.1 CMD 中执行：

```cmd
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip config set install.trusted-host pypi.tuna.tsinghua.edu.cn
```

### 2.2 验证配置成功：

```cmd
pip config list
```

期望看到：
```
global.index-url='https://pypi.tuna.tsinghua.edu.cn/simple'
install.trusted-host='pypi.tuna.tsinghua.edu.cn'
```

> **说明**：配置后，以后所有 `pip install` 都会自动走清华镜像，无需再加 `-i` 参数。

---

## 第 3 步：安装基础数据处理库

```cmd
pip install numpy pandas scipy matplotlib seaborn tqdm openpyxl
```

**作用**：
- `numpy`：矩阵运算
- `pandas`：读取 Excel / CSV
- `scipy`：科学计算
- `matplotlib` / `seaborn`：画图
- `tqdm`：进度条
- `openpyxl`：读写 Excel（label-100.xlsx）

**验证**：
```cmd
python -c "import numpy, pandas, scipy, matplotlib; print('基础库OK')"
```

---

## 第 4 步：安装音频处理库

```cmd
pip install librosa soundfile
```

**作用**：
- `librosa`：提取 MFCC、梅尔频谱、韵律特征
- `soundfile`：读取音频 WAV 文件（librosa 的依赖）

**验证**：
```cmd
python -c "import librosa; print('librosa版本:', librosa.__version__)"
```

---

## 第 5 步：安装视频与图像处理库

```cmd
pip install opencv-python Pillow
```

**作用**：
- `opencv-python`：读取视频、抽帧
- `Pillow`：图像格式转换

**验证**：
```cmd
python -c "import cv2; print('opencv版本:', cv2.__version__)"
```

---

## 第 6 步：安装 PyTorch（深度学习框架）

### ⚠️ 重要：这里必须指定 CPU 版本索引地址

```cmd
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
```

**作用**：
- `torch`：神经网络计算
- `torchvision`：ResNet-50 等预训练视觉模型
- `torchaudio`：音频处理支持

**为什么用 `--index-url`**：PyTorch 官方库不在 pip 默认源里，必须指定 PyTorch 自己的下载地址。这个地址在国内可以直接访问。

**验证**：
```cmd
python -c "import torch; print('torch版本:', torch.__version__)"
```

> **注意**：如果你有 NVIDIA 显卡且想使用 GPU 加速，需要去 https://pytorch.org/get-started/locally/ 选择 CUDA 版本命令。但数学建模竞赛不需要训练大模型，CPU 完全够用。

## 第 9 步：安装 FFmpeg（系统级工具）

FFmpeg 不是 Python 库，是独立的命令行程序，用于从视频中提取音频。

### 方法 A：自动安装（推荐，需要联网）

**在 PowerShell 中执行**（CMD 中 winget 可能不可用）：

```powershell
winget install Gyan.FFmpeg --accept-source-agreements --accept-package-agreements
```

安装完成后，**关闭当前终端窗口，重新打开一个新的 CMD/PowerShell**，再验证：

```cmd
ffmpeg -version
```

期望看到第一行：`ffmpeg version 6.x.x ...`

### 方法 B：手动安装（如果 winget 失败）

1. 浏览器访问：https://ffmpeg.org/download.html
2. 点击 **Windows builds from gyan.dev**
3. 下载文件名类似 `ffmpeg-7.x.x-essentials_build.zip` 的文件
4. 解压到 `D:\ffmpeg`
5. 将 `D:\ffmpeg\bin` 添加到系统环境变量 PATH：
   - 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
   - 找到 `Path` → 编辑 → 新建 → 输入 `D:\ffmpeg\bin`
   - 确定保存
6. **重启终端**，执行 `ffmpeg -version` 验证

## 第 10 步：配置 Hugging Face 国内镜像（模型下载加速）

运行代码时会自动下载 `roberta-base` 等预训练模型（约 500MB）。默认从 Hugging Face 美国服务器下载，速度慢。

### 10.1 当前会话生效（立即生效，关闭终端后失效）

**CMD 中**：
```cmd
set HF_ENDPOINT=https://hf-mirror.com
```

**PowerShell 中**：
```powershell
$env:HF_ENDPOINT="https://hf-mirror.com"
```

### 10.2 永久生效（推荐）

**CMD 中**：
```cmd
setx HF_ENDPOINT https://hf-mirror.com
```

**PowerShell 中**：
```powershell
[Environment]::SetEnvironmentVariable("HF_ENDPOINT", "https://hf-mirror.com", "User")
```

> `setx` 设置后需要**重启终端**才能在新窗口中生效。

**验证**：
```cmd
echo %HF_ENDPOINT%
```
期望输出：`https://hf-mirror.com`

## 常见问题速查

### Q: pip 安装时报错 `Could not find a version that satisfies the requirement torch`
**解决**：你没有加 `--index-url https://download.pytorch.org/whl/cpu`，PyTorch 必须从指定的索引地址安装。

### Q: `pip install` 速度依然很慢
**解决**：确认第 2 步的清华源配置成功（`pip config list`）。如果仍然慢，在当前命令后追加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。

### Q: `librosa` 安装失败，提示缺少 Microsoft Visual C++
**解决**：访问 https://aka.ms/vs/17/release/vc_redist.x64.exe 下载安装 Visual C++ 运行库，然后重新执行 `pip install librosa`。

### Q: 运行 `python run_unaligned_all.py` 时提示 `ffmpeg not found`
**解决**：FFmpeg 安装后必须重启终端才能生效。关闭 CMD 重新打开。
